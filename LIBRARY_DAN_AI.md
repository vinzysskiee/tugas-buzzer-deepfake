# Library dan Bantuan AI

## Library yang Digunakan

1. csv
   Digunakan untuk membaca file CSV.

2. json
   Digunakan untuk menyimpan laporan JSON.

3. pathlib
   Digunakan untuk mengelola lokasi file.

4. argparse
   Digunakan untuk membuat perintah aplikasi.

5. unittest
   Digunakan untuk melakukan pengujian program.

## Bantuan AI

ChatGPT digunakan sebagai alat bantu dalam:
- Merancang struktur aplikasi.
- Membantu penulisan kode Python.
- Menyusun dokumentasi program.
- Membuat skenario pengujian.

Seluruh kode perlu dipahami, dijalankan,
diperiksa, dan disesuaikan oleh mahasiswa.
